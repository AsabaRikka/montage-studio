# 软件更新说明

当前1.0.9仍采用“复制完整便携文件夹”的更新方式。更新前退出旧版，备份旧版实际 `MontageStudio/data`，将新版本解压到独立目录，再把完整 `data`（包括 `cloud`）复制到新版对应位置；保留旧版本目录，不同时运行两个版本处理同一份数据。

后续可实现主动检查更新：软件读取固定 HTTPS 地址上的公开版本清单 JSON（版本号、下载地址、SHA256、发布日期和说明），用户点击后下载完整 ZIP 到临时目录，校验 SHA256 后切换到新的版本目录。没有固定发布地址和签名密钥前，不在软件中声称已支持自动更新；正式上线时应增加代码签名，避免仅依赖哈希。更新过程不上传素材、不读取账号凭据，也不覆盖用户 `data`。
