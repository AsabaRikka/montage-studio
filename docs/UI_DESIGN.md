# 1.0.2 界面改造依据

本次为现有原生桌面软件的视觉与交互改造，不重建业务逻辑。用户明确要求复选框、多列素材展示、Logo，并参考 Codex 风格。design-taste-frontend 主要面向网页，React、SEO、营销 Hero、滚动动画等不适用于本项目；采用其先审查、克制层级、统一色彩/形状、完整状态和实际截图验收原则，使用已有 Qt 原生组件实现，不声称采用 Codex 官方设计系统。

原界面：蓝灰主色，微软雅黑，8px容器/5px按钮；五个流程页签，三等宽素材列表，逐行缩略图，Ctrl/Shift 多选，缺少显式勾选和程序图标。保留五页名称、参数字段顺序、批量覆盖保护、单条字幕、离线流程和本机历史。移除大面积蓝色按钮和三列窄列表。

设计读法：面向公司日常批量视频制作的工具，Codex 式中性、清晰、低干扰。DESIGN_VARIANCE=4、MOTION_INTENSITY=2、VISUAL_DENSITY=5；不使用装饰动画，密度优先给真实素材。侧栏流程导航，顶部当前页标题；素材按 A/B/音乐切换，铺满自适应多列网格，持久可见的复选框与选中边框，普通点击累加选择，保留 Ctrl/Shift、空格、全选。

浅/深色分别定义统一灰阶，无品牌渐变；按钮/输入8px、素材与容器12px。中文字使用Windows微软雅黑，字号13px，主标题22px。Logo为本项目原创拼接/播放标志，导航图标使用Tabler同一图标家族并附MIT许可。原生复选框语义/键盘交互和屏幕阅读名称保留。

验收需实际检查：空库引导、后台加载/失败、勾选与批量操作、多列/小窗口/高DPI/500项、浅深色五页、滚轮防误改、原业务端到端、独立冻结程序/发布校验。真实公司素材、音频质量和第二台物理电脑不属于本次自动验证。最终证据和未验证事项记入HANDOFF与PROGRESS。
