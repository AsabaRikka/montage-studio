# 混剪工坊 1.0.5 使用说明

## 历史记录预览和重新生成

在“本机历史”双击任意列可预览对应成片。选中记录后点击“删除选中记录”，Ctrl / Shift 可以多选。确认后只删除所选历史索引，输出视频、源素材和已完成任务保留；该A+B配对可重新使用。返回“组合计划”重新生成计划，再创建新导出任务并开始，旧任务中的完成项不会自动重跑。文件已移动或删除时会提示无法预览。删除前可先备份任务与历史；恢复备份会恢复当时的历史占用。

## 播放视频

双击素材或打开样片/成片后，下方进度条随播放前进，右侧显示当前时间/总时长。点击轨道或拖动圆点即可跳转；播放中拖动时暂时暂停，松手继续播放，暂停时跳转保持暂停。进度条获得焦点后，左右方向键前后1秒，Home到开头，End到结尾；滚轮不会误跳。播完点“播放”可以从头重播。字幕校正仍保留精确秒数输入。

## 飞书云端前贴

“素材”页点击“云端前贴”，已预填你指定的“AI前置钩子素材库”链接。先点“飞书连接”检查本机账号，再点“刷新云端目录”，勾选视频后点“同步选中到 A 前贴”。完成后切回“A 前贴”继续设置音乐、字幕、次数和混剪。双击已下载的云端卡片可播放；未下载时先同步。云端库可搜索描述、文件名、备注、制作人，也可仅看“是否直接可用”标记为“是”的记录。卡片悬停查看完整备注；备注如“从第五秒开始”只作为说明，不会自动截取或替换画面，请自行确认内容。

只读取链接所指视图的“成品文件”视频，不导入“参考视频”或其他表。需要更新时手动刷新和同步；重复同步复用已下载视频并按内容去重，保留本机字幕和使用次数。不向飞书写回，不会因为云端记录删除而自动删除本地前贴。同步失败或暂停后可重新勾选重试，已完成下载保留。正常混剪及已下载素材可离线使用，刷新和新下载需要网络及权限。

你当前电脑已有可用飞书连接。发给同事的包不含你的登录态：同事需要有这张表的查看和下载权限，并在“飞书连接”完成本机授权。有现有官方CLI连接可留空连接名称复用；新电脑点击“新电脑：填写公司应用配置”，向公司管理员取得已开通多维表格/知识库读取及附件下载的公司应用App ID、App Secret。填写后存入CLI独立的montage-studio连接，再点“登录 / 重新授权”，打开授权链接或扫描二维码，完成后点“我已完成授权，继续连接”。应用配置和账号凭据由官方CLI在本机管理，不写入软件session或发布包；不要把App Secret、令牌或CLI配置文件发给同事。

升级1.0.5：退出旧版，先备份实际data，再把旧版data整体复制到新版MontageStudio/data。数据库和内容历史规则未变化；原素材/任务/字幕延续。云端目录和视频保存于data/cloud，之后迁移软件时一起复制。CLI登录状态独立于软件data，换物理电脑需重新登录。不要用空data覆盖旧版，旧1.0.2目录保留。

这是 Windows 64 位便携软件，面向 Windows 10（1903 或以上）和 Windows 11，本次实测为 Windows 11。解压整个软件包，打开 `MontageStudio` 文件夹，双击 `MontageStudio.exe`。无需安装 Python、FFmpeg 或字幕模型。请不要只复制 EXE；同事使用时复制完整文件夹。建议放在本地可写目录，不要在压缩包内运行。

## 第一次使用

先用随包的演示素材走一遍流程，再用少量真实素材确认声音和字幕，最后运行大批量任务。

1. **素材**：填写游戏名称，分别导入 A 前贴、B 主视频和音乐。支持文件、文件夹和拖入；相同文件内容自动去重。同一游戏保持相同名称，才能避开该游戏的本机历史。
2. **画面与声音**：默认竖屏 720×1280、硬切、后台模式，B 保留原声。给 A 换音乐时选择音乐分配方式和音量。如果原片的口播与旧音乐混在一起，可选“尝试去旧音乐”；仅保留原声并加新音乐会同时留下旧音乐。分离有损，先导出一条试听。也可以提供单独纯口播音轨。
3. **字幕**：勾选添加字幕，在素材页选中 A，点“编辑 / 识别字幕”。可以离线识别、导入 SRT、提供文稿初步对齐，修改文字和时间并看帧预览。保存校正结果。字幕不是百分百准确，例如演示口播中的“工坊”可能识别为“公房”。原视频已有硬字幕不会被擦除。
4. **组合计划**：填数量、均匀或随机模式，或输入“生成1000条，均匀分配，不重复配对”，解析后生成计划。检查 A/B 次数和配对；可以双击配对列更换素材。单独指定某个 A 的次数或音乐，在素材页的单独设置中操作。修改设置后重新生成计划。
5. **导出队列**：固定任务后开始导出。固定后的组合、随机音乐和设置不会随着恢复任务改变。导出目录按任务分文件夹，包含成片 MP4、任务清单 CSV 和任务配方 JSON。完成后可直接播放成片。

无历史时，20 个 A、500 个 B 均匀生成1000条，A 各50次、B 各2次。每对 A+B 只算一种组合，换音乐、字幕或转场不会变成新组合。历史会减少可用数量；严格均匀无解时会提示，请调整数量或模式。计划预览不占用组合，固定但未完成的任务会占用组合。

## 新界面、缩略图和勾选

左侧导航切换五个流程。素材页上方切换 A 前贴、B 主视频、音乐库，页签显示总数；素材自动多列排列，窗口越宽显示越多。每张素材卡片左上有复选框，直接点击复选框或卡片即可累加选择，再次点击取消，不必按 Ctrl。Shift 连选、空格切换当前项、全选和取消选择仍可用。A/B 导入后后台生成缩略图，缓存供下次打开使用。双击可播放当前素材，多选时“播放原片”播放当前项。左下“切换深色 / 切换浅色”更换整套界面，重开保持偏好。

“移除选中”会批量移出列表，不删除原视频。“设置选中前贴 / 指定使用次数”支持同时修改多个 A 的声音和次数：只修改勾选的项目，其余设置和每条字幕保留。次数是每条所选前贴各自使用的次数，不是合计数；所有前贴次数总和仍须符合组合计划。“编辑 / 识别字幕”一次处理一条前贴，避免误用其他视频的口播。

下拉选项及数字框均禁止鼠标滚轮改值，获得焦点后也一样。鼠标在设置控件上滚动时仍可滚动页面；改值请点击下拉选项、输入数字或使用键盘和微调按钮。

## 音乐和过渡

音乐可整批固定、每个 A 随机固定、逐成片随机，也可给某个 A 单独覆盖。支持 A/B 分别设置；B 多数保持原声即可。设置音乐起点及音量，建议先听样片再决定。

硬切是默认过渡，适合快速批量输出，声音也直接拼接。淡入淡出、溶解、左擦除、左滑动会重叠两段视频，成片时长会减少设定的重叠时间，也可能叠住连接处的口播；这些画面转场可选择声音硬切或交叉渐变。

## 暂停、恢复和搬动素材

暂停会中断当前一条，已完成成片保留，当前条下次重新处理。重新打开软件，在队列选择原任务继续；失败任务可重试，不覆盖已完成成片。坏文件会单独标记失败，不阻止其他条完成。源文件移走后，用队列中的重定位功能指向内容相同的文件；内容被改过则需要重新导入、生成新任务。

放弃未完成任务会释放其未完成配对占用，已完成历史仍保留。删除磁盘上的成片不会清除配对历史。文件身份依据 SHA256 内容：改名、搬动、相同内容副本仍是同一素材；重新编码后的文件视为新素材，工具不判断视觉相似。

## 数据、备份和空间

一般在软件旁的 `data` 保存任务、本机历史、字幕校正和缓存；该目录不可写时使用 `%LOCALAPPDATA%\MontageStudio`。完整文件夹连同 data 搬走可保留本机状态。各同事历史独立，不自动共享。

升级到 1.0.5 时，先退出旧版，保留完整旧文件夹并备份 data；解压新版，再把旧版 `MontageStudio/data` 整个复制到新版 `MontageStudio/data`。不要用空白 data 覆盖旧版，不要同时运行两个版本处理同一份数据。本次未改变数据库或历史身份规则，复制旧data即可延续素材设置、任务与历史。云端缓存也随data迁移，CLI登录状态仍由本机单独管理。

在“本机历史”备份任务与历史，恢复会替换当前数据库，请先备份当前状态。数据库备份不包含原视频、输出成片或缓存，应另外保留素材。清理媒体缓存不会删除源视频、历史或手工校正字幕，下次需要重新识别/处理。

1000条90秒视频若平均4Mbps，仅输出约45GB，另需源素材和缓存空间。请使用空间充足的磁盘。后台模式顺序处理、降低子进程优先级并限制CPU线程；全速模式更占资源。NVIDIA编码不可用会回退CPU。实际速度取决于素材、转场、缓存和机器，不承诺固定每小时条数。

## 一句话与可选在线 AI

常见数量、随机、均匀、指定 A 次数等指令可以离线解析，不需要 API。复杂或矛盾的指令会被拒绝，可以改用表单。工具不根据视频语义自动配对。

可自行配置兼容接口，用 AI 解析规则。仅发送填写的规则文字，不发送视频、音频、图片或素材路径；费用由你配置的服务产生。密钥只在当前会话，重启后重新填写。不配置也能使用完整离线混剪流程。

## 遇到问题

保留导出任务清单中的错误信息；启动失败看 data/last_error.txt。确认整个软件文件夹完整、输出目录可写、原素材未被删除或修改、磁盘空间充足。暂停任务后可以切换CPU编码建立新任务作对照。

发布前已验证本机迁移目录与离线运行、字幕识别、音乐分离计算、播放、故障恢复和1000条合成短片任务。尚未验证第二台物理电脑；真实混合声音的分离效果需要你试听，游戏音效可能受到影响。合成示例不用于广告投放；平台要求和真实素材质量仍需业务检查。
