# 混剪工坊 1.0.0 交付记录

交付日期：2026-10-11。面向 Windows x64 的本机便携软件；默认竖屏 720p。完整便携包包含 FFmpeg、字体、中文字幕识别模型和音乐分离模型，不需要另装 Python。打开 MontageStudio/MontageStudio.exe，操作见随包使用说明。

## 已交付范围

A 前贴与 B 广告批量组合、随机/严格均匀/指定 A 次数、常见一句话规则、A/B 独立声音及多音乐分配、离线字幕识别/SRT/校正/帧预览、硬切和四种画面转场、任务固定/暂停续跑/失败重试/源重定位、SHA256 本机配对历史、备份恢复、CSV/JSON 导出报告。默认 B 保留原声；后台顺序处理、低优先级；NVIDIA 编码不可用回退 CPU。

无需配置在线 AI 就能完成上述流程。可选在线接口仅解析规则文字；本次验证未调用收费接口、未上传或处理公司素材。

## 验证依据

源码编译及 8 个单元测试通过。源码媒体自检 11 项通过；扩展验证包括中文离线识别、音乐分离计算、720p 成片完整解码、坏文件隔离、重试、暂停、重定位、备份恢复，以及原生界面导入到导出、实际视频帧解码播放、关窗重开。

20 个 A、500 个 B 的 1000 条合成短片任务全部导出；第 317 条后暂停、关闭并重新打开数据库，余下 683 条完成；历史为 1000 对，抽取 10 条分散完整解码。每段仅 0.2 秒、64×112，此结果用于验证调度与恢复，不能推算 90 秒/720p 的批量速度。

最终便携 EXE 的验证报告及截图随包保存在“验证记录”。验证使用迁移后的中文目录，PATH 仅保留 Windows 系统目录，外部模型缓存为空，字幕模型使用离线模式；媒体自检、完整扩展流程、启动截图全部通过，分别耗时14.8、49.19、2.74秒。打包脚本只有三项完整通过且EXE哈希一致才生成交付 ZIP。最终修复了SciPy动态模块漏收和构建环境ICU DLL冲突；支持Windows10 1903+或Windows11 x64，本机实测Windows11。

实际查看了界面、字幕帧和成片解码画面。音乐分离完成计算和数据检查，但尚未得到真实混合声音的人工试听确认；第二台物理电脑未验证。先用演示素材熟悉流程，再用少量真实素材校正字幕、试听口播/音效与音乐，确认后做大批量任务。

## 使用边界

换音乐不产生新的 A+B 组合；相同内容改名搬动仍使用同一身份，重新编码视作新素材；历史按本机和游戏名称记录。严格均匀不能满足时会拒绝计划。音乐分离是有损估计，不保证口播和游戏音效无损；字幕需校正。画面转场重叠会缩短时长，连接处的口播可能受到影响；硬切画面时声音直接拼接。后台模式控制资源占用，但不承诺办公软件完全不受影响。

随包合成示例仅用于操作演示。真实广告素材质量、平台要求和投放效果需业务验收。
